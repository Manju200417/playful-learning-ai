# Playful Learning AI  
### IIIT Hackathon Project — Learn by Playing

Playful Learning AI is a creative learning platform that transforms any study material into interactive quizzes, stories, and game-based experiences.  
Instead of reading long notes, learners understand concepts by playing, exploring, and interacting with the content.

---

## Features

### 1. Upload Any Resource
- PDF, text, notes, or OCR extracted content  
- Automatic cleaning and pre-processing  

### 2. AI-Powered Conversion
Our backend converts the uploaded content into:
- Quizzes (MCQ, True/False, Short answers)  
- Story-based explanation  
- Game-style learning tasks  
- Character-style teaching  

### 3. Engaging Learning Modes
- Story Mode: Learn through narrative and characters  
- Quiz Mode: Test understanding instantly  
- Game Mode: Explore → Guess → Unlock  
- Tutor Chat: Ask doubts related to the uploaded material  

---

## Tech Stack

### Backend
- Python Flask  
- SQLite  
- Groq API (Llama 3.1 Models)  
- OpenAI / Gemini LLM APIs (Optional)

### Frontend
- HTML, CSS, JavaScript  
- Responsive UI  

### Other Tools
- File upload system  
- Document parsing  
- AI prompt engineering  

---

## How AI is Used

- Groq API is used for fast, cost-efficient text generation.  
- LLMs generate quizzes, stories, explanations, and game-style interactions.  
- Prompt engineering is used to convert raw text into structured learning formats.
